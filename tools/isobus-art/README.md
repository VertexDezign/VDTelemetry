# ISOBUS machine art

Generates the machine SVGs the ISOBUS panel (issue #58) draws. See `isobus-assets.md` at the repo
root for what the panel needs and why; this file is about running the thing.

```bash
python3 tools/isobus-art/slurry.py     # tanker + its rear attachments
python3 tools/isobus-art/machines.py   # everything else
python3 tools/isobus-art/manifest.py   # re-measure the anchors off the art
cp tools/isobus-art/out/*.svg VDTerminal/app/src/commonMain/composeResources/drawable/
```

`out/` is git-ignored — everything in it is regenerated by the commands above. `preview.png` is the
whole set as committed.

## Why it emits two formats

`kit.py` writes each drawing twice from one op list:

- **SVG** — the deliverable. Compose Resources 1.11.1 generates `Res.drawable.<name>` for `.svg`.
- **PNG via ImageMagick MVG** — review only. This sandbox has no SVG rasteriser, and ImageMagick's
  internal SVG reader silently drops strokes and transforms, so it cannot render the deliverable to
  check it. MVG honours both. Because both backends read the same ops, the preview cannot drift from
  the shipped file.

Do not ship the PNGs.

## The body/fill mechanism

`Draw(layer)` takes `"body"` or `"fill"`. Every call paints on the body layer; only `cavity()` paints
on the fill layer. So one geometry pass produces both files and the cavity path is literally the same
numbers in each — they cannot misalign. Adding a tank means one `cavity()` call, not a second
drawing.

Keep a **generous margin of bodywork around every cavity**. The fill covers the cavity exactly, so
anything inside it vanishes at 100% and the machine has to still read as that machine.

## Gotchas worth not rediscovering

- **A horizontal spinning disc is edge-on** from the side *and* from behind — use `kit.spinner`,
  which draws a flattened ellipse with the vanes standing up. A face-on circle reads as a wheel.
- **The rear-view sprayer has no wheels.** From behind, a boom-mounted tank shows none, and inventing
  them read as wrong.
- **Material colours must stay clear of `BODY` (`#CFCC50`)** or the fill reads as bodywork. That is
  why `SEED` is `#B07C2E` and not the obvious wheat gold.
- **The palette is sampled from `mb_trac.png`**, not invented. Adding a new value (a bright steel, a
  white) breaks the family — the set is deliberately eight colours.
