Dein Hof auf dem zweiten Bildschirm

VDTelemetry exportiert den laufenden Spielzustand des Landwirtschafts-Simulators 25, und VDTerminal macht daraus ein Dashboard in jedem Browser - auf diesem PC oder auf dem Tablet oder Handy neben dir. Das geht in beide Richtungen: Über das Dashboard bedienst du auch die Maschine und den Hof.

Herunterladen Anleitung

Kostenlos und Open Source · Windows und Linux · Einzel- und Mehrspieler

In der Kabine und auf dem Hof

Die Maschine, die du fährst

Licht, Geräte, Tempomat, Lenkhilfe und AutoDrive direkt zur Hand, mit eigenen Ansichten für Spritzen, Streuer, Mähdrescher, Pressen, Futtermischwagen und Frontlader.

Eine Karte, die deine Felder kennt

Felder, Fahrzeuge und Points of Interest, dazu die Bodenebenen des Spiels - Früchte, Wachstum, Boden und die Karten von Precision Farming - als Überlagerung.

Auch zu Fuß

Außerhalb des Fahrzeugs übernimmt der Hof: Aufgaben, Fruchtfolge und die Karte auf einen Blick.

Dein eigenes Layout

Teile eine Seite in Kacheln und setz jedes Widget dorthin, wo du es haben willst - ein Layout für das Tablet in der Kabine, ein anderes fürs Handy.

Ein Kombiinstrument aus einem alten Handy

Der Anzeigemodus macht ein übriges Handy zum Kombiinstrument: Drehzahl, Geschwindigkeit, Tempomat, Gang und die Warnleuchten.

Apps

Alles, womit der Hof läuft, nur einen Tipp entfernt. Tippe auf einen Screenshot für die volle Größe.

Loslegen

Mods installieren

Leg FS25_vdTelemetry und FS25_additionalInputs (1.2 oder neuer) in deinen Mod-Ordner und aktiviere beide.

VDTerminal starten

Lade VDTerminal für Windows oder Linux herunter und starte es auf dem PC, auf dem das Spiel läuft. Keine Installation - Java ist dabei.

Dashboard öffnen

Öffne die angezeigte Adresse in einem Browser: auf diesem PC oder auf einem Tablet oder Handy im selben Netzwerk.

Die Anleitung geht jeden Schritt durch, mit dem, was du prüfen kannst, wenn etwas nicht erscheint.

Läuft mit deinen Mods

Alle optional. VDTelemetry erkennt jede davon, wenn sie installiert ist, und zeigt ihre Daten dort, wo sie hingehören.

Selbst bauen

VDTerminal ist nur eine Möglichkeit, die Daten zu nutzen. Die Mod schreibt alles als einfache JSON-Dateien nach modSettings/FS25_vdTelemetry/telemetry/ und liest Befehle aus einer einfachen XML-Datei zurück - so kann auch dein eigenes Dashboard, Stream-Overlay, Button-Box oder Heim-Cockpit damit arbeiten.

Das Datenformat ist im Readme der Mod beschrieben (Englisch), mit echten Beispieldateien für jeden Kanal.
